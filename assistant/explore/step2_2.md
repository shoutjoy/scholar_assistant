예시) 이론간 연결관계 
(1) 이론 간 연결 관계 (Theories ➔ Theories)
주의가 작동하는 기반(공간 vs 객체)에서 시작하여, 최종 디스플레이 설계 지침으로 진화하는 과정입니다.
[공간 기반 주의 이론 (Space-based Attention)]
(주의는 손전등처럼 특정 '시야각 공간'을 비춘다는 초기 이론) [16]
       │
       ▼ (한계 극복: 같은 공간이라도 분리된 물체는 다르게 처리됨)
       │
[객체 파일 이론 (Object File Theory)]
(주의는 공간이 아니라 '객체 단위'로 할당되며, 동일 객체 내 정보는 
 병렬 처리되어 정보 통합 속도를 극대화한다는 이론) [17]
       │
       ▼ (설계 원칙으로 승화)
       │
[근접성 호환성 원리 (PCP)]
(객체 파일 이론의 병렬 처리 이점을 활용하여, 정보 통합이 필요한 
 작업은 반드시 디스플레이 상의 정보들을 하나의 '객체'나 가까운 
 '공간'으로 묶어주어야 한다는 궁극의 호환성 대원칙) [19]
